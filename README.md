工业级高性能 Web3D 钢铁侠机甲格纳库爆炸拆解与空间手势交互系统。

---

## 🌟 核心特性 (Key Features)

- **工业级 PBR 渲染管线**：基于 Three.js 构建高保真物理光照与金属材质着色器，光泽与环境反射极其逼真。
- **Draco 几何体高倍率压缩**：运用 Google Draco 算法将复杂高精度机甲三维网格压缩 **68%**，实现首屏秒级极速载入。
- **空间手势隔空拆解交互**：深度融合 MediaPipe 视觉算法，支持摄像头手势隔空控制机甲部件爆发展开、合体组装与旋转观察。
- **高帧率跨端适配**：深度优化 WebGL 顶点渲染与 Draw Call 批处理，全场景交互稳定锁定 **60 FPS**。
